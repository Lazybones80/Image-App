Fast workflow
1. Copy a chord/triad picture or text.
2. Left-click Paste or press Ctrl+V.
3. Repeat for every chord.
4. Use Arrange Row or Arrange Grid.

Controls
Drag = move
Shift-click = multi-select
Blue dot = resize selected picture(s)
Arrow keys = nudge
Delete = remove
Ctrl+A = select all
Ctrl+C = copy selected
Ctrl+V = paste copied
Ctrl+D = duplicate
Add Text → click anywhere → type
Double-click empty space = add text
Double-click text = edit
